## 实际接口与待验事项

1. SDK 读取 512 个原始 uint16 强度计数，不提供实时波长轴。本版使用校验后的 F1520808 厂家 Sense 实际导出标定轴：1507.5447～1594.4369 nm，步长 0.157～0.185 nm，非均匀。拟合逐点使用实际波长。SDK 无法读回设备序列号，当前物理设备与该标定文件的对应关系未由接口独立证实，需操作员核验；详见 `docs/DEVICE_AUDIT.md`。
2. 软件不对保存的原始强度做平滑、背景扣除或平均；DLL 内部是否预处理未公开。平滑仅用于粗定位。20 μs 曝光、40 ms 轮询等为请求设置，不冒充硬件读回；65,535 为数据表示上限，不是经标定的线性范围。
3. 两路硬件采样时刻和帧序号不可用。保存主机单调接收时间和 `host_rx_approx` 质量，不用相同光谱数值断言重复硬件帧，不以约 25 Hz 的接收频率断言真实更新频率。
4. 按操作员选择，真实按压、实测漂移预留范围、加载峰形适应性、重复按压重复性及操作员算法审阅均待后续完成。训练门保持关闭。更改提峰算法或配置后，应重新处理历史原始光谱、重新训练，并保持训练与部署版本一致。
5. 较早饱和、SDK 冲突和停机调试会话均保留。排查确认旧 TOUCH 遗留读取进程后已关闭该冲突进程；新适配器增加占用保护及父进程退出清理。最终结论仅引用上述正常完成会话，未删除失败原始数据。
